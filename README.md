## Featured project

### [dhruvpatel78.com](https://dhruvpatel78.com): my resume as a 3D ride

My take on the [Cloud Resume Challenge](https://cloudresumechallenge.dev/). Scroll and a character travels through my career, from school in Mumbai to work in New York, changing vehicles and crossing the ocean by plane on the way. On a desktop you can leave the road and explore the world freely.

- **Front end:** plain HTML, CSS and JavaScript with Three.js. No framework, no build step, and every model and sound is generated in code.
- **Hosting:** S3 behind CloudFront, with ACM and Route 53.
- **Back end:** a view counter on Lambda and DynamoDB.
- **Delivery:** Terraform for all of it, deployed by GitHub Actions.
